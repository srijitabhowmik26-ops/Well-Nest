# Well-Nest
# 🏥 Healthcare Management System

A full-stack **Healthcare Management System** designed to simplify and organize interactions between **doctors, patients, and administrators** through a single web-based platform.

The system provides different functionalities based on the user's role, making it easier to manage doctors, patients, appointments, and healthcare-related information efficiently.

## ✨ Features

### 👨‍⚕️ Doctor

* Doctor registration and profile management
* View and manage patient information
* Manage appointments
* Access relevant healthcare information

### 🧑‍🤝‍🧑 Patient

* Register and manage personal profile
* View available doctors
* Book and manage appointments
* View appointment-related information

### 👨‍💼 Admin

* Manage doctors and patients
* Add, update, and remove doctor information
* Monitor and manage the healthcare system
* Manage overall system data

## 🎯 Purpose

The main goal of this project is to create a centralized healthcare platform where doctors, patients, and administrators can interact with the system according to their respective roles.

It demonstrates the practical implementation of **frontend development, backend development, REST APIs, database management, authentication/authorization concepts, and full-stack application deployment**.
